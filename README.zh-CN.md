# 卡坦岛仿制版

[English](README.md) · [在线游玩](https://catan-imitation.catan-imitation.workers.dev/)

这是一个使用 TypeScript、React、Vite 和 Cloudflare Workers 开发的浏览器桌游。基础玩法参考卡坦岛规则，原创的“商业公会”扩展增加了代币交易、资源兑换和密封拍卖。

## 项目功能

- 本地游戏支持四名玩家共用一个浏览器。联机游戏支持三至四名玩家加入匿名私人房间。
- 每局从空白棋盘开始，按蛇形顺序完成初始放置。每名玩家的第二个初始村庄会获得相邻产出地块的资源。
- 每局随机生成标准的 19 地块地图。公开的 `M1-` 地图种子可以复现布局。设置提供种子复制，以及需要确认的“重玩当前地图”和“新随机地图”。只有联机房主可以重开。
- 基础规则包含资源产出、强盗处理、建造、发展卡、海上贸易、玩家交易和计分。默认胜利目标为 10 分。
- 商业公会包含三个交易位、代币、全桌集会冷却、资源兑换、三轮密封拍卖、兑换券和奖品卡。
- 游戏提供内置规则说明、产出统计和无障碍资源图标。
- 界面默认使用英文，可在设置中切换为简体中文。响应式网页支持 PC、平板和 Mobile 浏览器。

## 技术组成

| 层次 | 实现 |
| --- | --- |
| 前端 | React、TypeScript、Vite 和响应式 CSS |
| 游戏规则 | 本地与联机模式共用的 TypeScript 模块 |
| 后端 | Cloudflare Worker，提供房间 HTTP 接口与 WebSocket 通信 |
| 数据库 | SQLite 支持的 Durable Objects；每个对象通过存储 API 保存一个房间 |
| 部署 | 同一个 Worker 从同一来源提供前端与后端 |

联机服务器验证玩家命令，并持久化房间的权威状态。服务器向每名玩家发送独立视图，保护对手手牌和密封出价。本地游戏在浏览器内存中运行，不使用联机数据库。

## 快速开始

需要 Node.js 22 或更新版本，以及 pnpm 11.7.0。版本要求见 [package.json](package.json)。

```bash
pnpm install --frozen-lockfile
pnpm dev -- --port 5173
```

访问 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)，可开发前端并使用本地游戏。开发联机游戏时，先停止该服务器，再运行前后端组合服务：

```bash
pnpm dev:worker
```

访问 [http://127.0.0.1:8787/](http://127.0.0.1:8787/)。本地开发不需要 Cloudflare 账户凭据。

## 验证

```bash
pnpm test
pnpm build:worker
pnpm test:worker
pnpm test:e2e
pnpm smoke:ui
```

这些命令检查领域规则与客户端、前端与 Worker 类型、Worker 运行时、浏览器交互和前端构建产物。测试准备及额外的 Worker 冒烟检查见[开发指南](docs/development.md)。

## 当前限制

- 联机房间使用六位房间码。不提供用户账户、公开匹配或旁观席位。
- 席位凭据保存在当前浏览器和站点来源下。刷新或重新打开页面可以恢复席位。清除站点数据会丢失凭据，不支持跨设备找回。
- 无活动房间在 24 小时后过期。活动连接会延后过期。房间持久化属于临时保存，不提供长期存档。
- 本地游戏为共享屏幕游玩，不提供私密手牌或刷新恢复。
- 当前不包含 AI 玩家或非标准棋盘尺寸。
