## Decisions

- Decision: keep the existing fixed board id scheme and generate per-hex edge ids instead of redesigning full shared board topology now.
- Reason: U001-U006 need enforceable legality in the current prototype without a risky board-coordinate rewrite.
- Tradeoff: neighboring hexes still do not share physical vertex ids, so future visual/topology polish should normalize shared intersections.

- Decision: keep `collectProduction()` pure for statistics and add `applyProduction()` for bank-mutating gameplay.
- Reason: statistics panels need hypothetical expected income, while gameplay needs bank exhaustion behavior.
- Tradeoff: callers must choose the correct function based on preview versus state transition.
